# LayoutSwitcher

Автоперемикач розкладки **EN / UK / RU** для Windows 10/11 (аналог Caramba Switcher / Mahou).
Один файл на Python, лише стандартна бібліотека, без мережевих викликів і без бекдорів: код можна прочитати.

## Можливості

- Після пробілу, Enter або Tab визначає, чи слово набране не в тій розкладці, стирає його, друкує заново й перемикає розкладку.
- Словники беруться локально: перевірка правопису Windows (офлайн), Hunspell, частотні списки `words_*.txt`, ваші вивчені слова.
- Самонавчання (можна вимкнути в меню трея): слово, тричі набране правильно, потрапляє у `learned.txt`.
- «Навчити зі своїх документів»: читає файли лише з папки, яку ви самі обрали.
- Чорний список програм (`blacklist.txt`), менеджери паролів уже додані в скрипті.

## Керування

| Дія | Клавіші / елемент |
|---|---|
| Конвертувати слово вручну (і вивчити його) | `Pause` |
| Увімкнути/вимкнути автоперемикання | `Shift+Pause` |
| Вийти | `Ctrl+Pause` |
| Пауза/відновлення | подвійний клік по іконці в треї |
| Меню | правий клік по іконці в треї |

## Запуск зі скрипта

```
py layout_switcher.py
```

Потрібен Python 3.9+ (python.org) на Windows.

## Словники (необов'язково, але рекомендовано)

Запустіть один раз, файли з'являться поруч зі скриптом:

- `get_wordlists.bat` завантажує частотні списки `words_uk.txt`, `words_ru.txt`, `words_en.txt`
  (hermitdave/FrequencyWords, OpenSubtitles 2018, CC-BY-SA 4.0).
- `get_dictionaries.bat` завантажує Hunspell-словники у папку `dictionaries/`
  (репозиторій LibreOffice dictionaries, дивіться ліцензії там).

Ці файли великі й мають власні ліцензії, тому в репозиторій не входять (див. `.gitignore`).

## Збірка

1. `build.bat` збирає `dist\LayoutSwitcher.exe` через PyInstaller.
2. Для інсталятора відкрийте `installer.iss` в Inno Setup 6 і натисніть Compile. Результат: `dist\LayoutSwitcher-Setup.exe`.

Поруч з `LayoutSwitcher.exe` тримайте `blacklist.txt`, `words_*.txt` і папку `dictionaries`.

## Приватність

- Жодних імпортів `socket`, `urllib`, `http`, жодних мережевих викликів.
- У реєстр (`HKCU\...\Run`) пишеться лише рядок автозапуску, коли ви вмикаєте відповідний пункт меню. Ще два перемикачі меню зберігаються в `HKCU\Software\LayoutSwitcher`.
- Вивчені слова лежать у звичайному текстовому `learned.txt` (мова, табуляція, слово): його можна відкрити, відредагувати або стерти з меню трея.
- Не вчимося в програмах з чорного списку, у класичних полях пароля, на словах з цифрами чи змішаним регістром.
- Пароль у браузері програма розпізнати не може, тому для браузера й менеджера паролів вимкніть навчання або додайте програму в `blacklist.txt`.
